title: "Support and troubleshooting"
description: "Find the right check, create a ticket and follow an existing request."
---

Open [Support](https://oddswire.io/app/support) in your workspace. Choose **Create a support ticket** to open the Intercom messenger, describe the issue and attach a screenshot if it helps.

Choose **View your tickets** to continue a conversation or check its progress. Requests opened before Intercom remain under **Previous support requests**. Keep follow-up information in the existing conversation so the team can see the full context.

## Check these first

| What you see | What to check |
| --- | --- |
| A locked feature or access denied | [Coverage](https://oddswire.io/app/coverage), your active add-ons and [availability](/availability) |
| No data credits or an unexpected balance | [Usage](https://oddswire.io/app/usage) and [credit rules](/usage) |
| An offline bookmaker or missing price | [Service status](https://oddswire.io/status) and the price's freshness or missing reason |
| A failed API request | The HTTP status, response `code` and `request_id`; see [Errors](/errors) |
| A request timed out | Check Usage before sending it again; delivery may have completed |
| No fair value or +EV result | Read the reference/exclusion reason; a missing reference is not a zero edge |

## What to include

Include the page or endpoint, what you expected, what happened, and the time and time zone. For an API issue, include the request ID and error code. For a missing price, name the bookmaker, sport and fixture.

Keep API keys, passwords, session tokens, webhook URLs and payment details private. Remove them from screenshots and snippets before attaching them.

If you cannot sign in, email [admin@oddswire.io](mailto:admin@oddswire.io). General account guidance is also available in the [Help Center](https://help.oddswire.io).

Discover sports and competitions, find fixtures, then request scoped odds. Native feeds preserve provider IDs and player-prop evidence alongside the canonical sports-data API.

**Base URL:** `https://api.oddswire.io` · **Authentication:** `X-API-Key` header · **Version:** REST v1

## Make your first request

```bash
curl --request GET \
  --url 'https://api.oddswire.io/v1/account/entitlements' \
  --header "X-API-Key: $ODDSWIRE_API_KEY"
```

API keys belong in headers, never in a URL or public documentation form.

This access check is free. It returns your actual features, namespaces and source scope. Data calls require separately approved access and an allocation; an account or API key alone does not unlock a feed.

1. Sign in to your [workspace](https://oddswire.io/app) and create an account-owned key in [API keys](https://oddswire.io/app/keys). Keep the key private.
2. Check [Coverage](https://oddswire.io/app/coverage) and [Usage](https://oddswire.io/app/usage), then use the returned entitlements to choose a namespace and source.
3. [Discover fixtures and request odds](/endpoints), or use the [signed-in playground](https://oddswire.io/app/playground). It starts with the same free access check; no request runs automatically.

Need an approved data scope? [Contact support](mailto:admin@oddswire.io) with your intended use and required coverage. Do not send API keys. Access is reviewed; there is no public self-serve paid plan or automatic grant.

## Advanced integration

History, WebSocket, fair prices and alerts are documented in **Advanced**. Account administration and restricted operator contracts live in **Workspace reference**. Check [current availability](/availability) before depending on any restricted capability. A published contract does not grant access or source-use rights.

Download [OpenAPI](/openapi.json), [AsyncAPI](/asyncapi.json) or the [WebSocket schema](/websocket.schema.json). The quick starts use standard HTTP tools against the hosted API; no private repository or SDK installation is required.

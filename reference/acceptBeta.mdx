Restricted invitation contract. Use only an invitation actually issued for your enrolled identity; signup does not provide one. This account/control/coverage operation consumes no REST data credits. Its authentication, role and access requirements still apply. See [Current availability](/availability).


Invite-only personal API beta. Signup grants no data access. Acceptance requires the exact enrolled identity/account, approved region and acknowledgment. Source permissions, expiry and environment are revalidated on data reads. Global beta administration requires a separately provisioned operator, not a customer owner/admin. Invitations are shown once and never placed in URLs. Notices are local previews only; billing/Terminal are separate.

`POST /v1/account/beta/accept`

## Authentication

`AccountSession`

## Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `X-Oddswire-Account` | header | No | UUID of an account where the signed-in user is a member; defaults to their oldest account. |

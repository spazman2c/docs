---
title: "cURL quick start"
description: "Read current account fixtures and odds over HTTPS."
---

Load your own API key into `ODDSWIRE_API_KEY` through your secret manager or a private environment file. Keep it out of shared shell history and source code.

## Check access

```sh
: "${ODDSWIRE_API_KEY:?Load your API key privately}"
printf 'header = "X-API-Key: %s"\n' "$ODDSWIRE_API_KEY" |
  curl --config - --silent --show-error --fail-with-body --max-time 25 \
    'https://api.oddswire.io/v1/account/entitlements'
```

## Find current fixtures

```sh
printf 'header = "X-API-Key: %s"\n' "$ODDSWIRE_API_KEY" |
  curl --config - --silent --show-error --fail-with-body --max-time 25 \
    'https://api.oddswire.io/v1/fixtures'
```

The default checks every bookmaker your account can access for football. Set `sport` to another sport in your plan. `bookmakers` is optional; omit it for the full account scope. Read `meta.bookmakers`, `missing[]` and `meta.next_cursor`.

## Read current odds

```sh
printf 'header = "X-API-Key: %s"\n' "$ODDSWIRE_API_KEY" |
  curl --config - --silent --show-error --fail-with-body --max-time 25 \
    'https://api.oddswire.io/v1/odds'
```

Optionally add `--get --data-urlencode "fixture=$FIXTURE_REF"`, using an exact `fixture_ref` from fixture discovery. Do not substitute an unscoped original ID.

Successful data pages cost one credit; errors and 304 are free. These commands do not retry or follow redirects. A network timeout can leave delivery uncertain; inspect usage before retrying. See [current data](/datasets) and [errors and credits](/errors).

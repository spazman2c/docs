# Oddswire public documentation

Published at https://docs.oddswire.io using Mintlify. docs.json lives at the repository root; main is the deployment branch.

This repository contains public technical documentation only. It includes no API keys, source prices, customer records or data-use grants. Signup grants no source data. Public quick starts use standard HTTP tools; SDK packages remain private previews and are not published.

The product repository exports these reviewed files with scripts/mintlify_export.py. Review exported changes before publishing; edits in this public repository or Mintlify editor are not automatically copied back to the product checkout. Reference contracts derive from its canonical schema. Do not introduce credentials or raw evidence here.

Hosted guide content is reviewed in docs/hosted in the product checkout. OpenAPI hosting/availability prose is overlaid without changing request parameters or response schemas. The canonical source contract remains separate.

description: "Check access against the hosted HTTPS API, then request a fixture only if your scope is approved."

Use cURL 7.76+ in a trusted terminal. Create your own key in [the workspace](https://oddswire.io/app/keys) and load it into `ODDSWIRE_API_KEY` through your usual secret manager or a private environment file. Never paste it into documentation, email, a URL or a shared shell history.

## 1. Check access without spending credits

Save this as `check-access.sh`, then run `sh check-access.sh`:

```sh
#!/bin/sh
set -eu
: "${ODDSWIRE_API_KEY:?Load your own API key into the environment}"
case "$ODDSWIRE_API_KEY" in
  *[!A-Za-z0-9_-]*) echo 'Unexpected key format' >&2; exit 1 ;;
esac
# The header is read from stdin instead of being placed in curl's arguments.
printf 'header = "X-API-Key: %s"\n' "$ODDSWIRE_API_KEY" |
  curl --config - --silent --show-error --fail-with-body --max-time 10 \
    'https://api.oddswire.io/v1/account/entitlements'
```

The response is a page with `data`, `missing` and `meta`. Inspect `data[0].namespaces` and `data[0].features`. Empty arrays mean no scope is granted; that is expected for a new account. This account introspection call is free, including when no data credits are allocated. A 401 means authentication failed; a 403 is not solved by changing the base URL.

## 2. Discover a fixture only after approval

Set `ODDSWIRE_NAMESPACE` to a value actually returned by your access check. Use only a namespace returned for your account. Run this separate command only when the account has `fixtures` access and an allocation:

```sh
: "${ODDSWIRE_NAMESPACE:?Choose an approved namespace from entitlements}"
printf 'header = "X-API-Key: %s"\n' "$ODDSWIRE_API_KEY" |
  curl --config - --silent --show-error --fail-with-body --max-time 10 \
    --get 'https://api.oddswire.io/v1/fixtures' \
    --data-urlencode "namespace=$ODDSWIRE_NAMESPACE" \
    --data-urlencode 'limit=1'
```

A completed successful data page costs one credit, including an empty page. Inspect `missing[]` as well as `data`. Use a returned `fixture.id` with [List odds](/reference/listOdds), in the same namespace. Do not assume an ID exists in another namespace.

These commands do not follow redirects or retry automatically. If a request times out, its delivery outcome may be unknown; inspect usage before deliberately retrying. Read [Errors and credits](/errors).

## Your first signed-in request

After verified signup, an owner or admin of a new empty workspace can [create a key](https://oddswire.io/app/keys) for the free entitlements check, without a beta invitation, data grants or credits. Open the [private playground](https://oddswire.io/app/playground) in the same tab: the entitlements endpoint is selected and your tab-memory key is filled into the private cURL/Python snippet. Public docs never receive your key. Copied snippets contain a credential: keep them private. A successful control response describes your current permissions; it does not grant odds-data access. Data reads still require separately reviewed access and an allocation.

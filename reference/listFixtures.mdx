Deployed REST contract; requires the current approved feature, namespace, source scope and allocation. Signup grants no data. A completed successful data page costs one credit, including an empty or insufficient page. Errors and 304 are free; a client timeout can leave delivery uncertain. See [Current availability](/availability).

`GET /v1/fixtures`

## Authentication

`ApiKey`

## Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `namespace` | query | Yes | Explicit pilot namespace; numeric IDs are scoped to it. |
| `limit` | query | No | Page size 1..100; default 25. |
| `cursor` | query | No | Opaque query-bound cursor; restart on 409 after data changes. |
| `fixture` | query | No | Comma-separated namespace-scoped fixture/group IDs (max 25). |
| `competition` | query | No | Comma-separated competition IDs. |
| `sport` | query | No | Comma-separated sport IDs. |
| `books` | query | No | Source/region IDs, not brand IDs (comma separated). |
| `from` | query | No | Inclusive UTC-normalized RFC3339 kickoff bound. |
| `to` | query | No | Exclusive RFC3339 kickoff bound. |
| `status` | query | No | Stored fixture state. |
| `If-None-Match` | header | No | Weak semantic ETag; freshness and access are revalidated before 304. |

Restricted test billing contract. Production paid checkout and payment-provider fulfillment are not enabled for general customers. This account/control/coverage operation consumes no REST data credits. Its authentication, role and access requirements still apply. See [Current availability](/availability).


Test-only billing; owner session required for mutations, owner/admin for reads. Fixed test catalogue; enrollment ceiling controls source access. Checkout returns do not activate grants. Retry unresolved mutations with the same request UUID. UTC credit cycles, no usage refill, overage off, no Terminal billing or data rights granted.

`POST /v1/account/billing/portal`

## Authentication

`AccountSession`

## Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `X-Oddswire-Account` | header | No | UUID of an account where the signed-in user is a member; defaults to their oldest account. |

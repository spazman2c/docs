## Before you start

Sign in to [your workspace](https://oddswire.io/app), then check [Coverage](https://oddswire.io/app/coverage) and [Usage](https://oddswire.io/app/usage). Coverage shows what your account can access; Usage shows your credits. New accounts start without source-data access or a credit allocation.

Saving a plan does not activate it. An available feature can also need permission for the selected bookmakers. See [availability and coverage](/availability) if a feature is locked or a price is missing.

## Build an integration

The REST API uses `https://api.oddswire.io` and an `X-API-Key` header. Start with the free [access check](/reference/getEntitlements), discover a fixture in a dataset your account can use, then request its odds.

Choose a complete example: [cURL](/quickstart-curl), [Python](/quickstart-python) or [JavaScript/TypeScript](/quickstart-typescript). Read [data conventions](/data) for price units and [errors and credits](/errors) for request handling.

Download [OpenAPI](/openapi.json), [AsyncAPI](/asyncapi.json) or the [WebSocket schema](/websocket.schema.json). AI-readable documentation is available at [/llms.txt](https://docs.oddswire.io/llms.txt) and [/llms-full.txt](https://docs.oddswire.io/llms-full.txt).

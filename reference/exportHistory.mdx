Private local pilot with account-wide included credits. Namespace-scoped IDs; overage off. Successful data pages cost one credit; account/errors/304/aborted or timed-out deliveries are free. No payment or source distribution rights are implied.

`GET /v1/history/export`

## Authentication

`ApiKey`

## Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `namespace` | query | Yes | Explicit namespace; history IDs are permanent source-local IDs. |
| `books` | query | Yes | One to eight entitled source/region IDs. |
| `native_fixture_id` | query | Yes | One to ten permanent source-local canonical fixture IDs from mappings.native_fixture_id. Not the upstream source_fixture_id or reviewed group ID. |
| `markets` | query | No | Comma-separated native payout families; default current entitled families. |
| `from` | query | No | Inclusive received seen_ts; required for ticks/coverage. |
| `until` | query | No | Exclusive received seen_ts; required for ticks/coverage; maximum 31-day interval. |
| `as_of` | query | No | Inclusive recorded confirmation cutoff. Required for snapshots/lines, cannot be in the future. |
| `scheduled_start` | query | No | Explicit scheduled kickoff; closing uses strictly earlier confirmations. Required for lines. |
| `kind` | query | Yes | Entire bounded selection; no implicit paging or asynchronous job. |
| `format` | query | Yes | One complete bounded file; one credit after successful delivery. |
| `If-None-Match` | header | No | Weak semantic ETag; freshness and access are revalidated before 304. |

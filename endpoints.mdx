Base URL: `https://api.oddswire.io`. Authenticate with your own `X-API-Key` header.

## Try three requests

1. [Check access](/reference/getEntitlements). Enter your API key and send this free request to confirm your account's access.
2. [Find fixtures](/reference/listFixtures). Current BetRivers PA data and scheduled fixtures are preselected in a three-record page. Press **Send**, then copy a returned `id`.
3. [Get odds](/reference/listOdds). Enter that ID as `fixture`. The same bookmaker, current feed and match-result market are already selected.

Your key's permissions and credit rules apply. Current prices can become unavailable when a source is stopped, a quote expires or access changes. The [current-data guide](/datasets) explains freshness and response fields.

## Calls

| Endpoint | Use it for |
| --- | --- |
| [Find fixtures](/reference/listFixtures) | Discover matches with optional bookmaker, competition and time filters |
| [Fixture details](/reference/getFixture) | Read one discovered fixture |
| [Get odds](/reference/listOdds) | Read current prices for a fixture or competition |
| [Teams and players](/reference/listParticipants) | Read available participant evidence |
| [Sports](/reference/listSports) | List sports |
| [Bookmakers](/reference/listSources) | List bookmaker/source identities |
| [Competitions](/reference/listCompetitions) | List competitions |
| [Markets](/reference/listMarkets) | List market families and periods |

Access, coverage and usage reads are free. Completed data pages follow the [credit rules](/errors).

## Build your integration

Use the [cURL](/quickstart-curl), [Python](/quickstart-python) or [JavaScript/TypeScript](/quickstart-typescript) quick start. The [API reference](/reference/listFixtures) contains the exact request fields and responses.

[Fair values](/reference/getFair), [reviewed mappings](/reference/listMappings), [WebSocket](/websocket) and [alerts](/alerts) have their documented access and compatibility requirements. A visible endpoint does not activate it for an account.

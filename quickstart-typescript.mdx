---
title: "TypeScript quick start"
description: "Read current fixtures and odds with built-in fetch."
---

Use Node.js 22+ and load your own `ODDSWIRE_API_KEY` privately. This example checks access for free. Set `ODDSWIRE_RUN_DATA=1` when ready for the two data calls.

```typescript
const key = process.env.ODDSWIRE_API_KEY;
if (!key || /[\r\n]/.test(key)) throw new Error("Load your API key privately");

async function getPage(path: string) {
  const response = await fetch("https://api.oddswire.io" + path, {
    headers: { "X-API-Key": key! },
    redirect: "error",
    signal: AbortSignal.timeout(25_000),
  });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return response.json();
}

console.log(await getPage("/v1/account/entitlements"));
if (process.env.ODDSWIRE_RUN_DATA === "1") {
  const fixtures = await getPage("/v1/fixtures");
  console.log("Bookmakers:", fixtures.meta.bookmakers);
  console.log("Fixture rows:", fixtures.data.length, "Missing:", fixtures.missing);
  const odds = await getPage("/v1/odds");
  console.log("Odds rows:", odds.data.length, "Missing:", odds.missing);
}
```

Both data calls include every bookmaker your account can access for football. Use `sport` for another sport in your plan. `bookmakers` optionally narrows the scope. Use a discovered `fixture_ref` as the URL-encoded `fixture` parameter to select a source fixture.

A completed data page costs one credit; errors and 304 are free. Follow `meta.next_cursor` with the same filters, restarting after 409. No automatic retries occur. Preserve decimal strings and original times; see [current data](/datasets) and [errors and credits](/errors).

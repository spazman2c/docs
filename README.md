# Oddswire public documentation

Published at https://docs.oddswire.io using Mintlify. docs.json lives at the repository root; main is the deployment branch.

This repository contains public technical documentation only. It includes no API keys, source prices, customer records or data-use grants. Signup grants no source data. SDK examples require the private product checkout; packages are not published.

The product repository exports these reviewed files with scripts/mintlify_export.py. Guide changes belong in its shared Markdown sources; reference contracts derive from its canonical schema. Do not introduce credentials or raw evidence here.

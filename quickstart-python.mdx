Use Python 3.9+ and your own account key in `ODDSWIRE_API_KEY`. This example uses the standard library; there is no `pip install oddswire` step. Do not copy a real key into the script.

Save the following as `check_access.py` and run `python3 check_access.py`. With only an API key set, it makes one free entitlements request. Data requests require an additional, explicit `ODDSWIRE_NAMESPACE` from your approved scope.

```python
import json
import os
from urllib.error import HTTPError
from urllib.parse import urlencode
from urllib.request import HTTPRedirectHandler, Request, build_opener

BASE_URL = "https://api.oddswire.io"

class NoRedirects(HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None

key = os.environ["ODDSWIRE_API_KEY"]
if not key or any(c in key for c in "\r\n"):
    raise SystemExit("Load a valid API key through your private environment")
opener = build_opener(NoRedirects())

def get_page(path, params=None):
    query = "?" + urlencode(params) if params else ""
    request = Request(BASE_URL + path + query, headers={"X-API-Key": key})
    with opener.open(request, timeout=10) as response:
        body = response.read(4 * 1024 * 1024 + 1)
        if len(body) > 4 * 1024 * 1024:
            raise ValueError("Response exceeds this example's size limit")
        return json.loads(body)

try:
    page = get_page("/v1/account/entitlements")  # Free access check.
    access = page["data"][0] if page["data"] else {}
    print("Namespaces:", access.get("namespaces", []))
    print("Features:", access.get("features", []))
    namespace = os.environ.get("ODDSWIRE_NAMESPACE")
    if namespace:
        if namespace not in access.get("namespaces", []):
            raise ValueError("Choose a namespace returned by entitlements")
        if "fixtures" not in access.get("features", []):
            raise ValueError("Fixture access has not been granted")
        fixtures = get_page("/v1/fixtures", {"namespace": namespace, "limit": 1})
        print("Fixture coverage:", fixtures["missing"])
        if fixtures["data"] and "odds" in access.get("features", []):
            fixture_id = fixtures["data"][0]["fixture"]["id"]
            odds = get_page("/v1/odds", {
                "namespace": namespace, "fixture": str(fixture_id), "limit": 3
            })
            print("Odds rows:", len(odds["data"]))
            print("Price coverage:", odds["missing"])
    else:
        print("No data request made. Set an approved namespace only when ready.")
except HTTPError as error:
    try:
        problem = json.loads(error.read(65536))
    except (ValueError, UnicodeError):
        problem = {}
    print("Request failed:", error.code, problem.get("code"), problem.get("request_id"))
    raise SystemExit(1) from None
except (OSError, ValueError, KeyError):
    print("Check configuration or delivery status; no automatic retry was attempted.")
    raise SystemExit(1) from None
```

The optional fixture/odds flow makes at most two data requests, which can consume two credits even when the responses are empty. No request retries or redirects occur. Network failures can leave delivery uncertain; check usage before retrying.

Prices and probabilities remain strings in JSON. Use `decimal.Decimal(value)` for arithmetic and retain `missing[]`, native identity and timestamps. Read [Data and coverage](/data) before comparing quotes.

## Your first signed-in request

Key creation currently requires approved API access; a new workspace cannot create a data key while beta access is disabled. Once your account is eligible, [create a key](https://oddswire.io/app/keys) and open the [private playground](https://oddswire.io/app/playground) in the same tab. It starts with the free entitlements check; your selected tab-memory key is filled into the private cURL/Python snippet. Public docs never receive your key. Copied snippets contain a credential: keep them private. This control response needs no credits and is an access check, not an odds-data request. Instant API access after signup is not currently available.

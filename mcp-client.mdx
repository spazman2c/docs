## Documentation search is separate from data access

Mintlify can expose these public docs to coding assistants. Its documentation MCP endpoint searches technical content; it does not return private odds, grant a source licence or need your Oddswire data key. Never give a documentation-search service your API credential.

## Data-client preview

The Oddswire data MCP client is a private, locally verified stdio implementation. It is not published to npm, has no public hosted data endpoint and is not available through signup. Do not try to install `@oddswire/mcp` from a registry or build it from this public docs repository.

If Oddswire supplies a reviewed preview artifact, use the exact installation and host instructions delivered with it. The runtime needs Node.js 22.23.4+, a permitted HTTPS API origin, an entitled namespace and an account-owned data key held in the host's private environment. It does not discover bootstrap credentials or accept account-management sessions. Use the ordinary [HTTP examples](/quickstart-python) for an integration you can build today.

## Implemented preview behavior

The preview exposes twelve bounded read tools: coverage/usage, sports, sources, markets, fixtures, odds, fair price, history coverage, ticks, snapshots and opening/closing lines. Each still requires the current API grants and, where applicable, history/source-purpose approval. A tool's presence does not make the feature available to your account.

Each tool makes at most one upstream attempt, without automatic pagination, retries or polling. The default process budget is twenty calls, configurable up to 100; one call is in flight at a time, with a ten-second timeout and 128 KiB output bound. Lists have at most ten rows and require an explicit cursor. Oversized results fail rather than silently dropping missing coverage.

Account/control calls are free; completed data pages may cost one credit, including empty pages. A response rejected by the MCP output bound may already have consumed a credit upstream. Transport failure is uncertain delivery, not proof of zero charge. Read [Errors and credits](/errors) before retrying.

The preview does not expose mutations, source collection, WebSocket calls or bet placement. Treat source text as untrusted data, preserve `missing[]` and timestamps, and do not turn an insufficient fair result into an asserted price.

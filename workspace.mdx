Open [your workspace](https://oddswire.io/app), sign in and complete email verification. Verified signup creates a personal workspace. New accounts start without source-data access or a credit allocation.

## Get set up

1. Check [Coverage](https://oddswire.io/app/coverage) for the bookmakers, regions and features available to your account.
2. Check [Usage](https://oddswire.io/app/usage) for your credit allocation and remaining balance.
3. Open [Customize plan](https://oddswire.io/app/plan) if you want to choose bookmakers, sports or add-ons. A saved selection is an estimate, not an activated purchase.
4. Choose a task below. If the access you need is missing, [contact support](/support) with your required bookmakers, sports, region and intended use.

Tools appear according to your active add-ons and permissions. API access and Terminal access are separate; buying or selecting one does not unlock the other.

## Set up an API key

Owners and admins can create a key in [API keys](https://oddswire.io/app/keys). Copy the value when it is shown and store it in your integration's secret settings. Each account supports one active key. Rotating it replaces the old key; revoking it blocks subsequent requests from integrations using it.

The existing signed-in Playground uses your account's active key automatically. You do not need to paste a secret to use it. External applications still need your API key; start with the free [access check](/reference/getEntitlements).

## Manage your account

Owners and admins manage keys and supported settings. Only the owner changes member roles. API data keys cannot manage membership or billing. Your workspace handles the login session; you do not need to copy session tokens into examples.

If a page cannot confirm access, refresh it once and check [Support](/support) if the issue continues. An unavailable check does not mean your account balance or saved records were erased.

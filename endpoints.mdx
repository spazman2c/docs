Base URL: `https://api.oddswire.io`. Authenticate with your own `X-API-Key` header.

## Try three requests

1. [Check access](/reference/getEntitlements). Enter your API key and send this free request.
2. [Find fixtures](/reference/listFixtures). Press **Send** to check every bookmaker your account can access for football. Change the sport if needed; the bookmaker filter starts empty.
3. [Get odds](/reference/listOdds). Press **Send** for current available prices across the same account scope. Optionally enter a returned `fixture_ref` to select a source fixture.

No dataset setup is required. `meta.bookmakers` accounts for the entire source scope, including bookmakers absent from the current page. Read `missing[]` for unavailable sources and follow `meta.next_cursor` for further records.

## Integrate

Use the [cURL](/quickstart-curl), [Python](/quickstart-python) or [TypeScript](/quickstart-typescript) quick start. Request fields and responses belong in the [API reference](/reference/listFixtures); [current data](/datasets), [authentication](/authentication), [credits](/errors) and [freshness](/odds-freshness) are explained in the integration guides.

Your account permissions and credit rules apply. Requests never activate access or start collection.

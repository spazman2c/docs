## Try current fixtures and odds

Enter your own API key in [Find fixtures](/reference/listFixtures) and press **Send**. The request includes **all bookmakers your account can access for the selected sport**. Football is preselected; change `sport` to another sport in your plan. No dataset selection or bookmaker filter is needed.

[Get odds](/reference/listOdds) uses the same account scope. Leave `fixture` blank to request current available prices across that scope, or copy a discovered `fixture_ref` to select one source fixture. `bookmakers` is an optional filter and starts empty.

## Coverage and pagination

`meta.bookmakers` lists every bookmaker checked, its current status and record counts across the whole request. A page contains up to 25 records by default; it is not the complete bookmaker list. Use `meta.next_cursor` for the next page with the same filters. If the feed changes and the cursor returns 409, start a fresh request without the cursor.

Read `missing[]` for unavailable sources, timeouts or missing coverage. One unavailable bookmaker does not suppress other bookmakers. Access to a bookmaker does not guarantee that current prices are available. Some source readers require a specific `fixture_ref` for odds; the response says so explicitly.

## Price freshness

Only eligible active prices are returned. Check `state`, `value`, `fresh_until` and the original times in `evidence`. `confirmed_at`, when present, records the source confirmation; otherwise use the source receive time. Response delivery does not refresh a quote.

Stale, suspended, stopped and unavailable prices remain withheld. An empty result can be valid when no current records are available in the requested scope.

## Fields and identity

- `bookmaker_id` is the immutable catalogue ID. Keep it with the sport and original fixture `id`.
- `fixture_ref` is an opaque request reference carrying that source and sport scope. Copy it unchanged when filtering odds.
- Matching original IDs or similar team names do not establish a match across bookmakers. Use only supplied reviewed `shared_fixture` identities for grouping.
- Odds preserve original market and selection IDs, line units, string-valued prices and evidence.
- `original` preserves the detailed original record. Do not convert prices or large identifiers to floating-point numbers.

See [Errors and credits](/errors) and [Data conventions](/data) for delivery, units and comparison rules.

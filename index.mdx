## Connect your application

**Base URL:** `https://api.oddswire.io` · **Authentication:** `X-API-Key` header · **Version:** REST v1

Your first request checks access without consuming data credits:

```bash
curl --max-time 10 \
  'https://api.oddswire.io/v1/account/entitlements' \
  --header "X-API-Key: $ODDSWIRE_API_KEY"
```

Then choose an entitled dataset, discover a fixture and request its odds. The [API overview](/endpoints) explains the route families. The [playground](https://oddswire.io/app/playground) lets you select a bookmaker and match and copy cURL, Python or TypeScript requests.

Keep credentials private, preserve decimal strings and read every `missing[]` entry. See [data conventions](/data) and [errors and credits](/errors).

Download [OpenAPI](/openapi.json), [AsyncAPI](/asyncapi.json) or the [WebSocket schema](/websocket.schema.json). Searchable text is available at [/llms.txt](https://docs.oddswire.io/llms.txt) and [/llms-full.txt](https://docs.oddswire.io/llms-full.txt).

For account access or coverage questions, [contact support](mailto:admin@oddswire.io). Include your request ID when available; never send a key or token.

title: "Python quick start"
description: "Read current account fixtures and odds with the Python standard library."
---

Set your own `ODDSWIRE_API_KEY` privately. This example makes one free access request. Set `ODDSWIRE_RUN_DATA=1` when ready to make the two data requests.

```python
import json
import os
from urllib.request import HTTPRedirectHandler, Request, build_opener

class NoRedirects(HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None

key = os.environ["ODDSWIRE_API_KEY"]
if not key or any(c in key for c in "\r\n"):
    raise ValueError("Load a valid API key privately")
opener = build_opener(NoRedirects())

def get_page(path):
    req = Request("https://api.oddswire.io" + path, headers={"X-API-Key": key})
    with opener.open(req, timeout=25) as response:
        raw = response.read(2 * 1024 * 1024 + 1)
        if len(raw) > 2 * 1024 * 1024:
            raise ValueError("Response exceeds the size limit")
        return json.loads(raw)

print(get_page("/v1/account/entitlements"))
if os.environ.get("ODDSWIRE_RUN_DATA") == "1":
    fixtures = get_page("/v1/fixtures")
    print("Bookmakers:", fixtures["meta"]["bookmakers"])
    print("Fixture rows:", len(fixtures["data"]))
    print("Missing:", fixtures["missing"])
    odds = get_page("/v1/odds")
    print("Odds rows:", len(odds["data"]))
    print("Missing:", odds["missing"])
```

Both data calls check every authorized bookmaker for football by default. `sport` selects another sport in your plan. To filter odds to a source fixture, URL-encode its exact `fixture_ref` as `fixture`.

A successful data page costs one credit. Follow `meta.next_cursor` with the same filters for more records; restart after 409. No automatic retry occurs. Preserve decimal strings, original identities and freshness times. Read [current data](/datasets) and [errors and credits](/errors).

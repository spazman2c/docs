Session-only Terminal product. Separate current Terminal grants and display/chart source-purpose/region reviews; API plans/keys and REST credits are not used. Private, no-store, bounded polling and native recorded history only.

`POST /v1/terminal/chart`

## Authentication

`AccountSession`

## Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `X-Oddswire-Account` | header | No | UUID of an account where the signed-in user is a member; defaults to their oldest account. |

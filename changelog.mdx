## 13 November 2026

- Added workspace guides for [plan customization and the seven optional add-ons](/plans), [Usage](/usage) and [account setup](/workspace).
- Documented [Odds board](/odds-board), [Terminal](/terminal), [+EV finder](/ev-finder), [Bet tracker](/bet-tracker), [Alerts](/alerts) and [Discord posts](/discord), including their access requirements and unavailable-data states.
- Bet tracker supports manual date/time entry, CSV preview and import, settlement, revision history, delete/restore and complete exports.
- Plans use the current published catalogue and refresh their estimates. Add-on selection and active feature access are separate.
- +EV shows an explicit insufficient-reference state when no eligible calculation is possible. A deployed page does not guarantee available opportunities.
- Documentation navigation now groups workspace guides, API integrations and MCP setup.

## 12 November 2026

- The [hosted MCP server](/mcp-client) supports Oddswire sign-in for compatible ChatGPT and Claude connectors, alongside API-key authentication.
- [WebSocket documentation](/websocket) covers server-side authentication, short-lived browser tickets and native snapshot delivery.

## 11 November 2026

- Added dataset aliases `sportsbooks`, `kambi` and `pilot`, opt-in `view=standard`, [participants](/reference/listParticipants) and [fixture detail](/reference/getFixture).
- Hosted HTTPS quick starts use standard tools and header credentials.

## Compatibility

The REST API uses `/v1`. Preserve original identifiers and tolerate added optional fields and missing/error codes. Check [current availability](/availability) and your account coverage before depending on a feature.

Open [+EV finder](https://oddswire.io/app/ev) when it is included in your active add-ons. It compares an offered price with an eligible fair-probability reference for the same outcome and settlement terms.

## Read expected value

For decimal odds `d` and fair probability `p`, expected return per unit staked is `p × d − 1`. A displayed 2% edge represents an estimated return of 0.02 per unit under that probability estimate; it does not predict the result of one bet.

A reference must be current, independent and suitable for the market. Several brands sharing a pricing feed do not count as independent evidence. Different settlement terms, suspended prices and stale observations can exclude a quote.

## Use the finder

1. Choose an available market and bookmaker scope.
2. Set the offered filters and minimum edge.
3. Read the reference, price age and exclusion reasons with each result.
4. Recheck a candidate before acting. If the source price, reference, access or market terms changed, the earlier result is no longer actionable.

Optional Kelly stake estimates depend on the supplied bankroll, fraction and cap. They are sensitive to probability errors and do not guarantee a profit or place a bet.

## Insufficient eligible reference

The page is deployed, but opportunity availability depends on your permissions and eligible reference coverage. The currently reviewed product scope has no approved independent sharp reference for live opportunities. When the page reports **Insufficient eligible reference**, no supported edge can be calculated. Automatic opportunity reads pause for that blocked scope; changing filters or repeatedly refreshing does not create a reference.

No result should be interpreted as a zero-risk trade or guaranteed return. See [fair-value conventions](/data#fair-price) and [current availability](/availability).

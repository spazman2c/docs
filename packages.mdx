---
title: "Client libraries"
description: "Integrate using standard HTTP tools and the downloadable API contract."
---

The public quick starts use [cURL](/quickstart-curl), the [Python standard library](/quickstart-python) and [Node.js fetch](/quickstart-typescript). No Oddswire package installation is required.

Official Python and TypeScript packages are not currently published on PyPI or npm. Do not install a similarly named package assuming it is an official Oddswire client. If support supplies a client artifact, use the instructions supplied with that version.

You can generate a client from the [customer OpenAPI contract](/openapi.json). Configure `https://api.oddswire.io`, keep keys in headers, preserve decimal strings and `missing[]`, and avoid automatic retries of uncertain metered requests.

To connect ChatGPT, Claude or another assistant, use the [hosted MCP server](/mcp-client). It does not require installing an SDK.
